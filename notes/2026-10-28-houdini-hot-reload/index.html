Houdini 热加载的坑：importlib 依赖序重载

2026年10月28日 · Houdini / Python

给 HouTools 写热加载框架时踩过的坑，记录一下结论。

问题

importlib.reload 只重载单个模块，模块之间有依赖时，重载顺序不对就会出现 「旧类对象还在被引用」的诡异现象：菜单点了没反应、属性面板是半新半旧。

解法：按依赖序重载

  1. 扫描包内模块，构建依赖图
  2. 拓扑排序，先重载被依赖的模块（从叶子到根）
  3. 重载完成后，薄分发器把入口函数重新绑定到新对象
graph 依赖图 → 拓扑排序 → 逐个 reload → 分发器重绑

遗留问题

  • 有状态的单例（如 UI 面板）重载时需要销毁重建，纯 reload 不够
  • hou.session 里的旧引用清理不干净时会漏内存

完整实现在 HouTools 仓库里。
