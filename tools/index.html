audio-cursor-zh

已发布

面向 VS Code 与 Trae IDE 的 Markdown 语音朗读工具。最初为 AI 辅助剧本创作而开发，希望让 AI 生成的剧本和文档不仅能阅读，也能通过语音听读。支持接入本地部署的 TTS 模型，同时提供 340+ 款微软自然语音及逐词高亮跟随等功能。
